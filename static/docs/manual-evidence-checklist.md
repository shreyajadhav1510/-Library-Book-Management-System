# Manual Evidence Collection Checklist for Academic Evaluation
> **Course**: CSE706 Agile Development using Scrum (Final Evaluation)  
> **Purpose**: A comprehensive inventory of external assets that must be generated or captured manually from Jira, GitHub, and real team activities.

---

## 1. Jira Artifacts & Screenshots Required

| Artifact # | Description | How to Obtain in Jira | Status |
|---|---|---|---|
| **JIRA-01** | **Scrum Board Screenshot** | Navigate to Jira Project -> **Active Sprints**. Capture board with columns: `To Do`, `In Progress`, `Done` showing cards assigned to both members. | `[Requires manual capture]` |
| **JIRA-02** | **Product Backlog Screenshot** | Navigate to **Backlog**. Capture view showing Epics panel (`EPIC-1` to `EPIC-4`), user stories with Story Points, and Sprint buckets. | `[Requires manual capture]` |
| **JIRA-03** | **Sprint 1 Burndown Chart** | Navigate to **Reports** -> **Burndown Chart** -> Select `Sprint 1`. Capture image showing remaining story points trending to zero. | `[Requires manual capture]` |
| **JIRA-04** | **Sprint 2 Burndown Chart** | Navigate to **Reports** -> **Burndown Chart** -> Select `Sprint 2`. Capture image showing story points burndown. | `[Requires manual capture]` |
| **JIRA-05** | **Velocity Chart Screenshot** | Navigate to **Reports** -> **Velocity Chart**. Capture graph displaying Sprint 1 (18 pts) and Sprint 2 (26 pts) committed vs. completed. | `[Requires manual capture]` |

## 2. GitHub & CI Artifacts Required

| Artifact # | Description | How to Obtain in GitHub | Status |
|---|---|---|---|
| **GIT-01** | **Repository URL & Homepage** | Push codebase to your team's GitHub repository. Capture homepage showing README and directory layout. | `[Requires manual capture]` |
| **GIT-02** | **Feature Branch & Pull Request** | Create a feature branch (e.g., `feature/circulation`), make commits, open a Pull Request into `main`. Capture PR page. | `[Requires manual capture]` |
| **GIT-03** | **Peer Code Review Comments** | In the Pull Request, have Team Member 2 leave a review comment or approval according to the Code Review Checklist. Capture screenshot. | `[Requires manual capture]` |
| **GIT-04** | **GitHub Actions CI Green Status** | Navigate to the **Actions** tab on GitHub. Capture run showing green checkmarks for Python 3.10 and Python 3.12 matrices. | `[Requires manual capture]` |
| **GIT-05** | **Git Commit Log / Network Graph** | Run `git log --graph --oneline` or view Insights -> Network on GitHub to display multi-member commit distribution. | `[Requires manual capture]` |
